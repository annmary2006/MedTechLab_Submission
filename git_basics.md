git init – This command creates a new Git repository in your project folder. Think of it as telling Git, “Hey, start tracking changes in this project.”

git add – This command stages your changes. It’s like saying, “I want to include these files in the next snapshot.” You can add a single file (git add file.txt) or all files (git add .).

git commit – This saves a snapshot of your staged changes to the repository with a message describing what you did. It’s like taking a photo of your project at that moment.
Example: git commit -m "Added homepage"

git push – This sends your committed changes from your local repository to a remote repository (like GitHub). Think of it as uploading your work so others can see it.
